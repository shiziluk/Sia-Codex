# Security Policy

## Reporting

Do not open a public issue containing credentials, authentication cookies,
private keys, personal account identifiers, or unredacted logs.

If GitHub private vulnerability reporting is available for this repository, use
it. Otherwise, open a minimal public issue that states only that you need a
private reporting channel, and wait for the maintainer to provide one.

## Scope

Sia-Codex is an unofficial downstream of CodexPlusPlus. Security reports should
identify the affected Sia-Codex commit and whether the issue also reproduces in
the upstream project.

## Local Data

The project should not ask users to submit API keys or login state in issues.
Reproduce with deterministic test values and redact all local paths and account
identifiers.
